## 🌟 English

### About Cleanfit

**Cleanfit** is a web-based outfit recommendation platform designed to help you discover personalized styling ideas. Whether you're getting ready for work, a date, or a casual hangout — Cleanfit suggests the perfect look for every occasion.

> 🚧 **This project is currently under active development.** Features are being built and updated regularly. Stay tuned!

### ✨ Planned Features

- 🎯 **Smart Outfit Recommendations** — Get curated outfit suggestions based on occasion, weather, and personal style
- 👔 **Style Exploration** — Discover trending styles like Cleanfit, Minimalist, Streetwear, and more
- 🖼️ **Visual Lookbook** — Browse outfit inspirations with a beautiful gallery interface
- 📱 **Responsive Design** — Seamless experience across desktop and mobile devices
- 🔖 **Save & Organize** — Bookmark your favorite outfits and build your personal style collection

## 🇨🇳 中文

### 关于 Cleanfit

**Cleanfit** 是一个基于 Web 的智能穿搭推荐平台，帮助你发现个性化的穿搭灵感。无论是通勤上班、约会聚会还是休闲出行 —— Cleanfit 为每个场景推荐最合适的穿搭方案。

> 🚧 **项目正在积极开发中。** 功能正在逐步构建和更新，敬请期待！

### ✨ 规划功能

- 🎯 **智能穿搭推荐** — 根据场景、天气和个人风格，为你推荐精心搭配的穿搭方案
- 👔 **风格探索** — 发现 Cleanfit、极简、街头等多种流行风格
- 🖼️ **穿搭画册** — 通过精美的画廊界面浏览穿搭灵感
- 📱 **响应式设计** — 在桌面端和移动端都能获得流畅体验
- 🔖 **收藏与整理** — 收藏喜欢的穿搭，建立个人风格收藏夹
