Technology / 精度主线

精度不来自
更重的单帧模型

BlazePose 的世界坐标是「模型先验尺度」，会把个体拉向人群平均值；单帧还有关键点抖动、遮挡误检与侧身透视缩短。Cleanfit 把精度拆成六个可验证的环节。

阅读算法说明 →
01 / 4D

3D 段长 × 时间序列

段长绕 Y 轴旋转不变（实测转体 90° 变化 0.000000），把「单帧猜测」变成跨时间的可复现测量。

02 / ROI

限定区域 · 段级过滤

鼠标直接拖框、拖边缩放、双击删除。框全身出全身数据，只框上半身只出上半身指标，可分段采集自动合并。

03 / POSE

姿态分桶 + 质量评分

五类姿态引导采样，避免 500 帧全是同一个姿势；可见度、ROI 命中率、朝向与运动模糊共同决定该帧是否收进。

04 / ROBUST

MAD 离群剔除

中位数绝对偏差剔除误检尖峰，再做 10% 截尾加权均值；每项输出 CV、离群数、样本数与收敛度。

05 / SCALE

外部尺度标定

已知身高、A4 同平面参照物、激光测距 + 参照物、仅激光四种方式，把模型先验尺度映射成真实厘米。

06 / DEVICE

多设备与深度源

多摄像头切换并入同一份样本；预留 CleanfitDepthSource 接口，接上 D4xx / LiDAR 即可自动并入标定。

关于硬件：本机 Intel RealSense SR300 的 Depth 设备在 Windows 中为 Error 状态，pyrealsense2 2.59 已移除该型号支持（query_devices() 返回 0 台），浏览器也读不了 Z16 / Y8 格式。因此当前绝对尺度由激光测距 / 已知参照物 / 已知身高这类外部基准提供，而不是假装已有深度真值。
