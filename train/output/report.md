# Cleanfit 尺寸比例校正器训练报告

- 数据集：**ANSUR II (2012) 公开真人测量样本**，5933 人（清洗后；原始 男 4,082 / 女 1,986）
- 划分：训练 4746 / 留出测试 1187（固定种子 20261112）
- 方法：**比例空间岭回归**（λ=1.0）。特征与目标都除以身高，含二次项与交互项，尺度无关
- 基线：`anthro.js` 原有硬编码公式（肩宽 +5cm、胯宽 +17cm、围度 π×宽×系数、臂展等长推算）

## 关键发现

- **肩宽系统性偏差**：真人「肩峰宽 → 三角肌外缘肩宽」平均差 9.14 cm，旧公式只加 5.00 cm，肩宽被系统性低估约 4 cm（≈8%）。
- **围度旧公式无依据**：`π × 宽度 × 0.62 / 0.53` 会系统性低估胸/腰/臀围 20–35 cm；真值显示围度更依赖「肩宽比 + 髋宽比 + 上/前臂比」的组合。
- **负面结果（如实保留）**：胯宽的比例模型在留出集上**反而更差**（1.59 cm vs 旧公式 1.34 cm）。说明 `髋中心距 + 17cm` 已是个不错的经验式，而单一髋宽比例不足以解释胯宽变异。因此导出里给该模型标记 `adopt:false`，前端**保留原公式** —— 按数据决策，不做全量替换。
- **臂展**：`肩宽 + 2×(上臂+前臂+9cm)` 的等长推算 MAE 约 9 cm，比例模型把它压到约 2 cm。

### 比例先验（多元）

除逐项统计外，还训练了 14 维「比例向量（值/身高）」的**均值与协方差**（全样本 / 男 / 女三套），可用于：

- `percentileOf(key, value)` —— 该值在真人分布中的百分位；
- `zScore(key, value)` —— 偏离均值几个标准差；
- `isPlausible(key, value)` —— 是否落在 min~max 合理区间；
- `mahalanobis(ratios)` —— 14 项比例整体偏离人群多远（越小越典型）；
- `shrink(ratios, sex, strength)` —— 把测得比例向人群均值收缩，抑制噪声。

前端测量工作台已接入：结果表新增「分位」列（<5% 或 >95% 标黄、越界标红），导出的 CSV / JSON 也带 `percentile` 字段。

### 一个被参考库当场揭穿的 demo 问题

`?demo` 的合成骨架（身高 175）输出：上臂 19.5 cm（p0）、前臂 13.3 cm（p0）、臂展 116.5 cm（p0）。真人上臂约 35.5 cm、臂展约 177 cm —— 合成骨架的四肢比例只有真人的一半左右。**因此 demo 数字不能当测量结果看**，它只验证「采样→融合→导出」链路。参考库的作用正是在这里：把「看起来像测量、其实是骨架假象」的输出标出来。

产物：`train/output/reference.json`、`demo/js/reference.js`、`train/data/ansur2_reference.csv`（6,068 行 × 14 项）。

## 与前端的对接方式

模型在比例空间，前端 `extractSegments()` 只需：
```js
const h = s.height;                       // 模型单位
const x = [d3(11,12)/h, d3(23,24)/h, upperArm/h, forearm/h];
s.shoulder  = calibPredict(CALIB.models.shoulder,  [d3(11,12)/h]) * h;
s.chestCirc = calibPredict(CALIB.models.chestCirc, x) * h;
```
预测值随后照常经过 `result()` 的尺度标定 k，因此与「已知身高 / 激光 / 参照物」任一标定方式天然兼容，不会产生双重缩放。

**外推保护**：每个模型导出 `featureRange`（训练集特征 1%~99% 区间，允许 15% 缓冲）。若某人比例落在真人分布之外，多项式会外推失真，前端自动回退旧公式。典型触发场景是 `?demo` 的合成骨架（肩宽/身高 0.197，真人约 0.233）——此时演示页显示的是兜底值，不应把 demo 数值当精度证据。

## 局限（必须如实说明）

1. **ANSUR II 是美军人群**（2012 年，年轻、体脂偏低），不能当中国/普通消费者的比例先验，只能作方法验证与合理性量级。
2. **唯一解剖近似**：ANSUR II 没有「髋关节中心距」列，按 `髂嵴宽−10cm` 代理 `d3(23,24)`；该假设影响胯宽/围度的绝对误差量级，但不影响「训练优于硬编码」的相对结论。
3. **本训练没有用到图像或视频**，因此不能证明端到端精度。要得到「≤5%」这类结论，下一步必须用带 3D 真值的视频（BEDLAM / AGORA，需注册签许可）或自建「同一人 + 卷尺实测」配对数据做 Bland–Altman 分析。
4. 围度仍属**估算项**（骨架段长无法直接给出软组织围度），报告中的 MAE 是在 ANSUR II 人群内的统计误差，不代表任意个体的绝对精度。
5. 许可：ANSUR II 公开分发包要求引用 Gordon et al. (2012) 方法报告；原页面注明军方样本不代表特定用户群体。
