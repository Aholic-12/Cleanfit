# ESP32 双激光对射测宽

用两个 ToF 激光测距模块「对射」，直接测出人体宽度：

```
W = B − dL − dR
```

- `B`：两个激光出光口之间的基线，用卡尺量，写进固件
- `dL` / `dR`：左右两侧激光到人体表面的距离
- `W`：宽度（肩宽 / 胯宽，取决于安装高度）

误差量级 **±3–7 mm**（基线误差 1mm + 单侧测距 2mm 时约 ±3mm）。

## 接线

| 信号 | ESP32-S3 | VL53L1X L | VL53L1X R |
|---|---|---|---|
| 电源 | 3V3 | VIN | VIN |
| 地 | GND | GND | GND |
| I2C 数据 | GPIO8 | SDA | SDA |
| I2C 时钟 | GPIO9 | SCL | SCL |
| 关断 | GPIO4 | XSHUT | — |
| 关断 | GPIO5 | — | XSHUT |

> 不同 ESP32-S3 开发板的默认 I2C 引脚不同。以你板子丝印为准，改 `.ino` 顶部的 `PIN_SDA` / `PIN_SCL` 即可。
>
> **两个 VL53L1X 出厂地址都是 `0x29`**，必须靠 XSHUT 分时上电改地址（固件里已处理：先放 L 改成 `0x30`，再放 R 改成 `0x31`）。

## 机械要求（决定精度的地方）

1. **刚性**：两个模块固定在同一根不形变的梁上。手拿着测，精度会掉到厘米级。
2. **共线**：两束光轴尽量在同一条直线上，偏差 < 0.5°（0.25m 处约 2mm 误差）。
3. **同高**：两束光在同一水平面。测肩宽就都装在肩高（约 1.4m）。
4. **垂直体轴**：光轴垂直于人体矢状面，人不要转身。
5. **避开眼睛**：装在肩高，低于成人眼睛（约 1.6m）；加遮光罩，防止儿童直视。

## 烧录

1. Arduino IDE 安装 ESP32 开发板包（Arduino-ESP32 3.x）。
2. 库管理器安装：
   - **Adafruit VL53L1X**
   - **WebSockets**（Links2004）—— 仅 Wi-Fi 模式需要
3. 打开 `esp32_laser_gate.ino`，改：
   - `BASELINE_MM`：你的基线（卡尺实测，单位 mm）
   - `WIFI_SSID` / `WIFI_PASS`：留空则只走 USB 串口
4. 选板子（ESP32S3 Dev Module）→ 烧录。

## 协议

USB 串口 **115200**，每行一个 JSON：

```json
{"t":1234,"dL":247,"dR":243,"B":700,"ok":1}
```

| 字段 | 含义 |
|---|---|
| `t` | 上电毫秒数 |
| `dL` / `dR` | 左右距离，mm；`-1` 表示无回波 |
| `B` | 基线，mm |
| `ok` | 1 = 两路都有效 |

Wi-Fi 模式下同一份 JSON 通过 `ws://<ip>:81` 广播。

## 浏览器测试

打开 `demo/laser.html`（需 https 或 localhost）：

- **连接串口**：Chrome/Edge 的 WebSerial，直接读 USB 串口，无需装驱动。
- **连接 WebSocket**：填 `ws://<esp32-ip>:81`。
- **模拟数据**：没有硬件也能先看界面。

## 标定与验证（必须先做）

1. 卡尺量 `B`，写进固件，误差控制在 ±1mm。
2. 找 **10–20 个人**，同一站姿，卷尺量肩宽（三角肌外缘，即 `bideltoid breadth`）。
3. 每人记录：卷尺值、激光值。
4. 算 **Bland–Altman**：偏差（bias）与一致性界限（LoA）。

判定标准：

- `|bias| < 5mm` 且 `LoA < ±10mm` → 方向成立。
- 偏差大 → 先查「激光是否对准最宽点」和「衣物厚度」，不要急着换传感器。

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 只有一个传感器初始化成功 | XSHUT 时序或接线 | 确认两路 XSHUT 都接到 GPIO，且上电时先拉低 |
| 读数一直跳 ±2cm | 光斑落在衣物褶皱 / 手臂边缘 | 让被测者穿贴身衣物、手臂自然下垂；或加遮光筒收窄 FOV |
| 读数为 -1 | 超出量程或表面太黑 | VL53L1X 短距模式约 1.3m；换浅色衣物或缩短基线 |
| 两台互相干扰 | 同时发光 | 固件已改为轮流单次测量；不要改成连续模式 |
| 数值整体偏大 | 基线量错 / 光轴不平行 | 重新量 B；用直角尺校准两束平行 |

## 安全

- VL53L1X 是 **Class 1（905nm）**，正常使用人眼安全。
- 仍然：**不要直视出光口**，不要对准儿童眼睛，加遮光罩。
- **不要**用 Class 3B / 4 的工业激光做对射。

## 与统计校准的关系

- 激光是**实测**（似然），统计先验是**范围**（先验）。
- 有激光锚点的项（肩宽、胯宽）以激光为准；没有锚点的项仍可用先验兜底。
- 激光还能当**异常检测**：算出 60cm 肩宽，立刻知道标定坏了。
